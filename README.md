# HTML and CSS Practice

> **This repository is archived.** It is a set of learning exercises kept as a
> record, not a project and not a library.

Ninety files written while working through HTML and CSS from the beginning:
24 HTML pages, 54 stylesheets, and the images and video they load.

## What is in here

Each file is one idea, tried on its own:

| Area | Files |
|------|-------|
| Layout | `box.html`, `cssboxmodel`, `blockelement`, `display`, `float`, `float1` |
| Colour | `color`, `colorhexa`, `colorchange`, `backgroundgradients`, `background` |
| Type | `fontfamily`, `firstline` |
| Selectors | `descendentChild`, `cssvariables` |
| Structure | `banner`, `twopages`, `twopagesmy`, `form`, `index` |
| Applied | `calcfun` (a small calculator), `django` (template markup) |

`CSS1/` and `HTML5/` hold the earliest exercises, before the files moved to
the top level.

## Why it is kept

It is the starting point of the web work that followed — the Django projects
and the vending machine's checkout page all render templates that began as
exercises like these. Nothing here is reusable and none of it is meant to be;
it is a record of learning the language rather than an artefact built with it.

There is no build step, no dependency and no framework. Open any `.html` file
in a browser.

## Rough edges left as they are

Two filenames in `HTML5/` are broken — `<!DOCTYPE html>.html` and files saved
without an extension (`django form`, `form django`). They are the result of a
save dialog getting the filename rather than the content, and on Windows the
angle brackets make them awkward to check out at all. They have been left
alone: renaming files in an archived record of what was actually written
would make it a less accurate record.
